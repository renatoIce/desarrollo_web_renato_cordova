Esperando que el usuario de este programa se encuentre bien, le comento el funcionamiento, esta web requiere primero su registro, posterior a su registro tendrá 
acceso a registrar su actividades, se registra una a una y quedará un historial de los registros, tambien tienes acceso a ver la lista de los miembros que se han 
registrado en la web, puedes ordenar o filtrar dependiendo de lo que necesites.
Tambien puedes acceder a gráficos básicos para visualizar los datos.
